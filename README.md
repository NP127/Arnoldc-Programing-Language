# ArnoldC Instalation guide
## Requirments
  java 26 ^
## Installation for Java
1. Download and install the latest JDK from https://www.oracle.com/java/technologies/downloads/.
2. Open a new terminal and verify the installation:
  ```sh
  java -version
  ```
3. If either command is not recognized, add Java's `bin` directory to your system `PATH`.

## Installation for Arnold C
  1. Download the ArnoldC java package from https://lhartikk.github.io/ArnoldC/

  2. Verify the installation by compiling ArnoldC program:

    ```sh
    java -jar ArnoldC.jar Hello_World.arnoldc
    ```
  3. Run the compiled program:
    ```sh
    java Hello_World
    ```

## Keywords

| Keyword | Description |
|---|---|
| `IT'S SHOWTIME` | Starts the program. |
| `YOU HAVE BEEN TERMINATED` | Ends the program. |
| `HEY CHRISTMAS TREE` | Declares a variable. |
| `YOU SET US UP` | Assigns a value to a variable. |
| `TALK TO THE HAND` | Prints a value. |
| `GET TO THE CHOPPER` | Starts an expression. |
| `HERE IS MY INVITATION` | Sets the initial expression value. |
| `ENOUGH TALK` | Ends an expression. |
| `BECAUSE I'M GOING TO SAY PLEASE` | Starts a conditional statement. |
| `YOU KNOW WHAT?` | Starts an else branch. |
| `BULLSHIT` | Ends a conditional statement. |
| `STICK AROUND` | Starts a loop. |
| `CHILL` | Ends a loop. |
| `LISTEN TO ME VERY CAREFULLY` | Defines a function. |
| `GIVE THESE PEOPLE AIR` | Returns a value. |
| `I'LL BE BACK` | Calls a function. |
| `TRUE` / `FALSE` | Boolean values. |
| `NO PROBLEMO` | Equality operator. |
| `YOU'RE FIRED` | Not-equal operator. |
| `LET OFF SOME STEAM, BENNET` | Addition operator. |
| `KNOCK KNOCK` | Subtraction operator. |
| `GET DOWN` | Multiplication operator. |
| `I WANT TO ASK YOU A BUNCH OF QUESTIONS` | Division operator. |
